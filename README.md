# Consultas de Odontopediatría · Proyecto final

**Vibe Coding CEDIA 2026 · registro VC-2026-037**

Simulador clínico web para que estudiantes de Odontología practiquen el manejo de caries en niños y adolescentes, con tres casos ficticios por edad, fichas de tiempo clínico y retroalimentación. Un piloto con 16 estudiantes de octavo semestre mostró una valoración de 4,8 sobre 5.
